# تثبيت طموحون عبر GitHub Pages

1. في Apps Script، افتح **نشر ← إدارة عمليات النشر** وانسخ رابط تطبيق الويب المنتهي بـ `/exec`. قارن الرابط مع وجهة زر **فتح طموحون** في `index.html`. عدّل الوجهة إذا اختلف الرابط. الوجهة المرفقة مأخوذة من معرّف النشر الذي ظهر في سجل المتصفح سابقًا.
2. أنشئ مستودعًا باسم `tamouhon-install` وارفع محتويات الحزمة إلى جذر الفرع `main`، مع إبقاء مجلد `icons` باسمه.
3. من **Settings → Pages** اختر **Deploy from a branch → main → /(root) → Save**. بعد اكتمال النشر، استخدم رابط Pages المعروض في الإعدادات.
4. افتح رابط Pages على الجوال وأضفه للشاشة الرئيسية من قائمة Chrome على أندرويد أو من قائمة المشاركة في Safari على آيفون. بعد فتح الأيقونة اضغط **فتح طموحون** للدخول إلى المنصة.

GitHub Pages يستضيف صفحة الاختصار وأيقوناتها. الموقع وعمليات تسجيل الدخول تعمل عبر رابط Apps Script وصلاحياته الحالية.
